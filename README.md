# setmeup

Set me up as fast as you can!

A personal, declarative machine-provisioning tool: converge any fresh OS install to your preferred tools and configuration, idempotently.

## Status

In planning. Shape captured as OpenSpec changes:

- `setmeup-core` — the product (manifest, secrets vault, identity, per-OS backends, TUI, bootstrap)
- `dev-workflow` — the agentic development scaffold (contract, skills, CI, this workflow doc)
- `dev-governance` — development policy (issue → change flow, PR review gate, quality gates)

## Development

This project is developed by AI agents under a spec-driven workflow. See [docs/workflow.md](docs/workflow.md) and [AGENTS.md](AGENTS.md) for the full story.
